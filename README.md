# Проектирование высоконагруженного облачного мессенджера (аналог Telegram)

## Расчётно-пояснительная записка. Курс «Архитектура высоконагруженных приложений».

## 1. Тема и целевая аудитория
### 1.1. Тема проекта
Проектируется **облачный кросс-платформенный мессенджер** - сервис обмена сообщениями в реальном времени для массового конечного пользователя, в котором вся переписка, медиа и состояние клиента хранятся на стороне сервера, а клиентские приложения выступают синхронизируемым кэшем.

Реальный аналог - **Telegram**.
### 1.2. Целевая аудитория
**1.000 млн пользователей в месяц;  500 млн в сутки**[1]
Аудитория глобальная, с перевесом в Южной и Юго-Восточной Азии, на Ближнем Востоке и в Северной Африке, в СНГ, Европе и Латинской Америке.
#### 1.2.1. Распределение аудитории по регионам
Официальной постранной разбивки MAU Telegram не публикует.
Проведённая оценка:
- измеряемая аудитория в России: 95,98 млн MAU (январь 2026) и 72,2 млн среднесуточной аудитории (март 2026) по данным Mediascope [2, 3];
- распределение установок приложения за 2025 г. по странам (Индия - 104 млн, Россия - 34,4 млн, Индонезия - 27,2 млн, США - 26,9 млн) [4];

### 1.3. Ключевой функционал MVP

| №   | Функция                                    | Содержание                                                                                                                                                    |
| --- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Отправка и доставка сообщений**          | Личные и групповые чаты: текст, ответы, пересылка, редактирование, удаление, реакции                                                                          |
| 2   | **Список чатов и синхронизация состояния** | Лента чатов с сортировкой по последнему сообщению, счётчики непрочитанного, статусы прочтения, черновики, синхронизация между всеми устройствами пользователя |
| 3   | **История переписки**                      | Постраничное чтение истории, переход к произвольному сообщению, доступность истории на новом устройстве без переноса данных                                   |
| 4   | **Вложения**                               | Фото, видео, голосовые сообщения, файлы до 2 ГБ: загрузка, хранение, превью, потоковая раздача                                                                |
| 5   | **Каналы**                                 | Публикация в канал с неограниченным числом подписчиков, счётчик просмотров, лента подписок                                                                    |
| 6   | **Поиск**                                  | Полнотекстовый поиск по всем сообщениям пользователя и внутри отдельного чата, поиск по чатам и публичным каналам                                             |
